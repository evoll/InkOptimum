# Dropbox

Просмотр папок Dropbox и загрузка книг на SD прямо с веб-страницы **/plugins** (книга должна быть в одной сети с телефоном или компьютером).

## Подготовка
1. На dropbox.com/developers/apps создайте приложение: *Scoped access*, тип *Full Dropbox* (или папка приложения), права `files.metadata.read` и `files.content.read`.
2. Скопируйте **App key** (секрет не нужен: используется PKCE).
3. Включите *Настройки → Система → Плагины*, откройте страницу плагинов, вставьте App key, нажмите «Open Dropbox», разрешите доступ и вставьте показанный код.

## Как работает
- Запросы к `api.dropboxapi.com` идут через книгу (`api.relay`), токен обновления хранится в браузере (localStorage), не на SD.
- Файл скачивает сама книга по временной ссылке Dropbox (`api.fetchToSd`), частями по 1 МБ с докачкой, в папку `/Dropbox/<путь в Dropbox>` (папку можно сменить в поле SD).
- Показываются форматы книг (EPUB, FB2, FB3, MOBI, TXT, DOCX, PDF и т. д.); кнопка «Download all books here» качает все книги папки.
- Действия очереди заданий: `list {path}` и `download {path}` (после входа в браузере).

Не проверялось на устройстве. Ограничения: ответ relay до 64 КБ (список читается страницами по 100 записей), токен привязан к браузеру.
