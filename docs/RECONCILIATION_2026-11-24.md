## 3. Что из плана не реализовано (по коду)
Перепроверено чтением кода/grep; в таблицах FEATURE_MATRIX исправлена устаревшая строка про предзагрузку (теперь глубина 3).
* Крупные отдельные проекты: Arabic/Myanmar-шейпер, RTL-интерфейс и RTL-листание, Niqqud, Indic без HarfBuzz, встроенные шрифты EPUB (`@font-face`), CSS по листам стилей.
* Из Folio: PIN-блокировка и защищённые книги, полки/автостатусы, личный словарь, heatmap на главной, цепочка запасных шрифтов для текста книги.
* Из XtApp: нет интерфейса для сброса `lockscreenApp`; BLE, TTF/pattern, трансформации изображений; `ctx.net:websocket` без Wi-Fi-запроса (ошибка `wifi`).
* Библиотека: корневые папки и индекс — «сверить» (не закрыто).
* Синхронизация: AlReaderX/FBReader (нужны образцы файлов); `vo`-смещения закладок неприменимы.
* Компаньон, этап 0: старые `/api/*` и WebDAV без токена; экран «Связь с телефоном»; остальные `/api/v1/*` (приложение ведётся в другом чате).
* Не делаем: расшифровка официальных .xtapp.
