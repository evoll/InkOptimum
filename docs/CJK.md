# CJK-типографика

Что сделано (SECTION_FILE_VERSION 74):

- **Ширина знаков препинания** (JLREQ для японского, CLREQ для китайского; таблицы в `lib/CjkPunct`, ширины в 1/8 em):
  закрывающая скобка/точка/запятая перед другим знаком отдаёт пустую половину em; открывающая скобка после знака
  сужается, а её рисунок сдвигается (`wordDrawShift`), чтобы чернила остались на месте глифа; средняя точка — на половину сдвига.
- Знак препинания в CJK-тексте — отдельный «слог» ParsedText (приклеен к соседу, если кинсоку запрещает перенос).
- **Зазор CJK–латиница**: четверть em между иероглифом/каной и латинской буквой или цифрой — только для `ja`, `zh`, `lzh`.
- Профиль выбирается по языку книги: `ja` → японская таблица, `zh-Hant/TW/HK/MO/lzh` → традиционная, остальные `zh` → упрощённая.
- Кривые кавычки считаются CJK-знаками, только если шрифт рисует их во всю ширину.

Не реализовано: правила начала/конца строки (push-in), сетка в целый em, точки-выделения, вертикальный текст, CJK-шрифты интерфейса.
Проверено только юнит-тестами (`test/cjk_punct`, `test/parsed_text`); на устройстве не тестировалось.
