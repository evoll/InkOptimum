# Подпись прошивки (Ed25519)

Цифровая подпись отвечает на вопрос «кто выпустил образ». SHA-256 из релиза GitHub отвечает только на вопрос «скачалось без ошибок»: тот, кто подменит релиз, подменит и его.

**Формат** (общий с Folio по идее, свой по префиксу): подписывается сообщение `"INKOPT-FW-v1\n" + SHA-256(весь .bin)` (45 байт), подпись — 64 байта, лежит рядом как `<образ>.bin.sig`. Префикс — часть формата: подпись другого проекта не пройдёт.

**Что в репозитории**
- `lib/FirmwareSignature` — проверка (`fwsig::verifyDigest(publicKey, digest, signature)`); ключа в библиотеке нет, его передаёт вызывающий. Нулевой ключ означает «не настроен»: `keyConfigured()` возвращает false, `verifyDigest` всегда false.
- `lib/Monocypher` — Monocypher 4.0.2 (CC0 или BSD-2), Ed25519 по RFC 8032.
- `tools/sign_firmware.sh` — подпись и вывод публичного ключа массивом C.
- Тест `test/firmware_signature` проверяет подпись, сделанную независимо (Python `cryptography`), и цепочку «openssl → библиотека».

**Выпуск**
1. `openssl genpkey -algorithm ed25519 -out ~/.inkoptimum/signing-ed25519.pem` (OpenSSL 3+). Файл не коммитить.
2. `tools/sign_firmware.sh --public-key` — массив для константы прошивки.
3. На каждый релиз: `tools/sign_firmware.sh .pio/build/<env>/firmware.bin`, загрузить `firmware.bin.sig` в релиз.

**Подключено** (ключ вписывается в `src/network/FirmwareSigningKey.h`; все нули = проверка выключена, всё как раньше):
- OTA: берёт из релиза ассет `<образ>.sig` (парный выбранному `.bin`), скачивает после проверки SHA-256 и сверяет с хэшем образа до прошивки; нет `.sig` или подпись неверна — образ удаляется, ошибка `SIGNATURE_ERROR`. При включённой проверке OTA всегда идёт через staging на SD (прямая запись в раздел не проверяется до записи).
- Обновление с SD (экран): рядом с файлом нужен `<образ>.sig`, иначе «Подпись прошивки отсутствует или неверна».
- Аварийные файлы-триггеры при загрузке остаются без подписи сознательно: это восстановление при физическом доступе.
- Политика: образ без подписи **запрещён**, когда ключ задан.

Не проверено на устройстве.
