Сравнены: **наш** InkOptimum, inkmod (`faaa43d`), crosspoint (`86bde44`), CrossInk (`9914146`), Paperio-Reader (`1537aaf`), papyrix-reader (`a40c17d`), witchhunt-reader (`89ef347`).
Метод: README и документы репозиториев, содержимое `lib/`, `src/activities/`, поиск по коду (75 + 70 проверочных шаблонов), точечное чтение спорных мест. Это **наличие кода и описание**, а не проверка работы на устройстве; ни одно значение «есть» у других репозиториев не запускалось. «~» — есть частично или по-другому. Где поиск шумный (общие слова), решение принято чтением кода.

Обозначения: ✔ есть · ~ частично · — нет · ? не удалось выяснить.

## 4. Порядок дальнейшей работы (по сверке)

1. Мелкое: запасной шрифт интерфейса с SD (пункты «сортировка файлов», «разделитель/центрирование строки состояния» и «папка загрузки OPDS» проверены чтением кода: уже есть, из таблицы убраны).
2. Спящий экран: выбор картинки из списка, тональная коррекция, замена обложки картинкой.
3. Чтение: выделение перетаскиванием, маркер, встроенные сноски без лимита.
4. Сверки «~»: плавающие изображения, буквицы, таблицы, фоновая вёрстка, шрифты EPUB.
5. Отдельные проекты: Arabic/Myanmar/RTL-UI (witchhunt), обновление SDK.
6. Вне объёма без отдельного решения: игры, LocalSend, принтер, Pomodoro, платы других производителей.
